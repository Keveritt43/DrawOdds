## Pronghorn horn length

[IDFG's controlled-hunt table](https://fishandgame.idfg.idaho.gov/ifwis/huntPlanner/stats/?game=pronghorn&season=controlled&yr=2025) reports annual average horn length, horned and hornless harvest, but does not state the number of animals whose horns were measured or a male-only average. Some rows include hornless harvest. The existing five-year `avgSize5` is a weighted estimate based on reported horned harvest rather than a confirmed count of measured horns. It must not be presented as a verified mature-buck average or substituted for a deer/elk antler-share percentage. The Idaho trophy model does not use it; missing comparable animal evidence uses a neutral input and the resulting tier is provisional. Historical observations are retained.

## Hunter-facing checks

The live Idaho 1042 hunt detail and mobile Find Hunts card showed Excellent (80), with matching Quality (81). The mobile trophy map key showed one Excellent unit for the 1042-only search. A live CSV export and the trophy filter also returned 80. An overlapping-elk table initially showed entire elk seasons rather than the days shared with the deer hunt; the revised table displays shared open dates, preserves closed gaps and warns that displayed hunter counts can overlap. It does not add the counts or alter scores.
