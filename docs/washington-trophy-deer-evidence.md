# Washington trophy comparison: deer types

Washington's [2026 big game regulations](https://wdfw.wa.gov/sites/default/files/publications/02706/wdfw02706.pdf) list GMU 117 permit 1007 for white-tailed buck and 1008 for mule deer buck. They share a GMU but their legal animals differ. The hunt-level resolver uses an explicit single deer type in the published legal-animal description for Washington controlled hunts. A generic or mixed description, conflicting deer-type field, or mere geographic location does not establish a type. A general hunt does not inherit the curated special-permit blacktail source merely because its unit and animal match.

The v5 comparison independently uses an explicit deer type in the exported hunt name to narrow reference rows; the export name is context, not independent proof of eligibility. In the November 21, 2026 six-state deer/elk/pronghorn export, the Washington comparison moved from 84 to 76 unresolved subspecies association rows; some hunts instead correctly have no matching reference type. All counts are associations and do not establish score errors. V5 is an audit reference, not the scoring authority.

On the retained 2026 Washington hunt snapshot, comparing the previous and updated resolver gave identical hunt-level scores for all 863 deer hunts (including unscored cases). Reasons for explicit mule-deer special hunts can change because their reference no longer erroneously includes whitetail. This comparison does not prove every live row is identical or make the broader trophy model quota-independent. Read-time scoring remains in use; no database import or synchronization is required for this change.
