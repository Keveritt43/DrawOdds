# Idaho wildfire pilot validation

Snapshot: November 2026. The NIFC historical perimeter service supplies 2018–2019 and WFIGS supplies 2020–2026. The Idaho bounding-box query returned 4,184 unique source records; year-by-year counts, query conditions and SHA-256 hashes are recorded in `data/id-fire-provenance.json`. These counts include polygons crossing the bounding box that do not intersect an Idaho unit. The current year is partial. ArcGIS geometry was generalized to 10 m; invalid shapes were repaired and collapsed shapes were refetched at original resolution. Repair can affect detailed geometry; the result is for approximate screening.

Each year is clipped to the unit and unioned before acreage is calculated; selected periods are unioned again, so overlapping records and repeat fires do not simply add acreage. Unit 76 includes overlapping 2018 North Eden records, providing a duplicate-record check. The NIFC 2024 Valley Fire final perimeter reports about 9,904 acres, consistent with the [Idaho Department of Lands report](https://content.govdelivery.com/accounts/IDLANDS/bulletins/3bd1f1b). This check is for the whole fire, not any individual unit intersection.

The packager requires the same 100 unit IDs as the existing terrain pilot, checks every image hash and dimension, validates joint remote and high-remote cell areas against the corresponding terrain totals, and checks source-record identity counts. Tests cover period-bit selection, requiring all selected attributes on a single cell, missing units, cross-state isolation, combined filters, and saved filter parameters. Run the full suite and application build before release. Wildfire area is not used in scores; the release performs no database import or schema change.
