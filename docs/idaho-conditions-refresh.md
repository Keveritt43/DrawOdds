# Idaho conditions refresh and release

The published unit and statewide layers are dated snapshots. NOAA's separate snow model is fetched live and reports its own valid time. Automatic agency sync remains disabled. The existing build scripts were written for November 2026: they hard-code years, dates and cache paths. **Do not rerun them as a current refresh without updating and reviewing those assumptions.**

For a manual refresh, work on a feature branch. `node scripts/id-conditions-stage.cjs 2026-11-22 2026-11-17` stages the selected as-of date and weekly USDM Tuesday in a new directory under `out/id-conditions-candidates/`; replace both dates for a later refresh. It downloads drought and snow candidates and the selected year’s fire perimeters, recording URLs, counts and hashes. The wildfire service returns records available at download time; the as-of argument limits the discovery year, not subsequent revisions. It does not rebuild assets or publish data. Existing candidate directories are never overwritten. Download the official US Drought Monitor weekly shapefile, NRCS station observations and NIFC perimeter inventories. Record the exact source URLs, requested periods, download timestamps, record counts and SHA-256 hashes. Confirm each source's observation date from its data, not the download date. Preserve past observations; missing coverage is unknown. Check for truncated pages, duplicate object IDs, invalid geometry and missing units. Do not overwrite the last reviewed source cache.

Update the currently date-specific downloader and builders together, including the observation date, fire-year range and age buckets. The unit GeoJSON, statewide drought layer, charts, unit filters and their metadata must all come from the same reviewed inputs. Verify drought geography and category percentages against official maps and unit summaries; compare fire years and snow station readings with representative official records. Run `npm test`, typecheck and build; inspect maps, legends, dates and overlays on desktop and mobile. Review the diff, record counts, changes and limitations, and deploy only the validated artifacts. Never change a date label alone or make the static snapshots sound live. This procedure does not authorize an Idaho agency database sync, a schema operation or a scheduled job.

A complete date-parameterized refresh pipeline is still needed; the current scripts are not yet safe for unattended or routine refreshes.
