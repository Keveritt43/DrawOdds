# Idaho visual conditions validation

The unit-map build `scripts/id-visual-build.py` reads the previously recorded fire and conditions snapshots and NIFC history for 2010–2017. Source counts and SHA-256 hashes for the added years are in `data/id-visual-meta.json`; the 2018–2026 source provenance remains in `data/id-fire-provenance.json`. A unit's most recent fire year wins in each approximately 100-m sampled cell. Output has a transparent pixel for no mapped 2010–2026 perimeter, which does not establish that no earlier or undocumented fire occurred. Charts divide each age band's sampled cells by all sampled unit cells, not by only burned cells.

Each of the 100 unit PNG checksums and climate GeoJSON assets is verified by `tests/idVisual.test.ts`, including the station association and category domain. The D1+ union reconstructed from the simplified displayed drought polygons was compared with full-resolution drought percentages for all 100 units; maximum absolute difference was 0.14 percentage points. Unit 54 has nonzero pixels in each of the four age categories. NOAA's snow water equivalent layer is live from its public ArcGIS service, whose footprint metadata supplies the analysis valid time; a missing timestamp or failed layer must not be represented as a current measurement. Station history is an independent dated snapshot. UAT must exercise overlay checkboxes and charts on desktop and mobile, including source failures and combined-layer visibility.
